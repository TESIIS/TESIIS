功能特色

災害發生時，快與準最重要

從搜尋、定位到導航，每一步都設計成在慌亂的時候也能一眼看懂。

全臺一次搜尋

支援名稱、地址與災害類型篩選，一次涵蓋全臺 22 縣市的官方資料，不必先選縣市再慢慢找。

自動找最近的

取得定位後立刻列出最近的收容處所與步行時間，搜尋半徑會隨著地圖縮放自動調整。

座標品質透明

每一筆都標示座標來源與精確度。概略位置會明講是概略，不會讓你把它誤認成災時的實際開放入口。

三種官方底圖

內政部國土測繪中心 WMTS 的電子、地形與正射影像底圖自由切換，看地形或看實景都行。

一鍵開始導航

從設施詳情直接叫出手機上的地圖 App 開始導航，不用抄地址、不用切換視窗重新輸入。

周邊交通資訊

顯示避難所附近的公車站、台鐵與高鐵站及距離，方便規劃徒步路線或安排轉乘。

怎麼用

三步就能出發

建議平常就先開一次，把住家與公司附近的收容處所記起來。

1

開啟地圖

用瀏覽器打開就能用，不必下載 App、不必註冊帳號。手機加到主畫面後就像原生 App 一樣。

2

允許定位

同意取用位置後，最近的收容處所會依距離排好。不想給定位也沒關係，直接搜尋地址一樣查得到。

3

出發前往

點開設施看容納資訊與座標品質，確認後按下導航，交給你慣用的手機地圖 App 帶路。

資料來源

資料從哪來，可靠到什麼程度

主要資料來自內政部消防署「避難收容處所點位檔」，每一筆進系統前都要通過座標品質檢查。

政府官方點位檔

上游約 5,973 筆全臺資料，通過座標品質閘門的 5,854 筆（98.0%）才會進入系統，其餘因座標明顯落在所屬縣市範圍外而被排除，被拒清單也一併公開。

上游掛掉也查得到

上游服務正常時抓最新資料；一旦上游失敗或回傳筆數異常，會自動退回進版控的全國快照，地圖照樣能查——災時最不能接受的就是打不開。

不需要任何金鑰

避難所資料與國土測繪中心底圖都不需要 API Key。任何人 clone 下來 docker compose up 就能跑起一套完整的自有部署。

這是查詢輔助工具，不是官方災害應變系統

TESIIS 幫助你事先掌握避難收容處所的位置與資訊。但災害真的發生時，請務必以各地方政府的即時公告與現場人員的指示為準。
